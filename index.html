โปรแกรมขายหน้าร้าน (POS) สำหรับจัดการสต๊อกสินค้า ระบบสมาชิก และบันทึกยอดขายแบบ Offline-First บน Windows

ความสามารถหลัก

  • บันทึกการขาย ตัดสต๊อกสินค้า และสะสมแต้มสมาชิกบนฐานข้อมูล SQLite ในเครื่อง
  • ซิงค์ข้อมูลยอดขายเข้า Google Sheets ของผู้ใช้งานอัตโนมัติเมื่อออนไลน์
  • สำรองไฟล์ฐานข้อมูลเข้า Google Drive ของผู้ใช้งานอย่างปลอดภัย
  • พอร์ทัลดู Dashboard คาดการณ์สินค้าขายดี/ควรเพิ่ม/ควรลด รายการขาย และ Stock จากนอกร้าน

เข้าสู่ระบบผู้จัดการร้าน (นอกร้าน)

กรุณาเข้าสู่ระบบด้วย Gmail ที่เป็นเจ้าของ หรือได้รับแชร์ไฟล์ Google Sheet ของร้าน (SaleTD_รายงานยอดขาย_...) เท่านั้น เพื่อความปลอดภัยของข้อมูลร้าน

⚙️ ยังไม่ได้ตั้งค่า Web Client ID ในไฟล์ config.js
นำ OAuth Client ID (ประเภท Web application ที่ใส่ Origin https://jakapot1729.github.io) มาวางเพื่อทดสอบทันที หรือใส่ถาวรใน config.js
🔎 ไม่พบไฟล์ Sheet อัตโนมัติ?
หากไฟล์ถูกแชร์มาแล้วค้นหาไม่พบ ให้วางลิงก์หรือ Spreadsheet ID ของ Google Sheet ร้านได้ (Google จะตรวจสิทธิ์ของ Gmail นี้จริง)
🔒 ระบบขอสิทธิ์ อ่านอย่างเดียว (Read-Only) ไม่แก้ไขข้อมูลใน Sheet และไม่เก็บข้อมูลยอดขายไว้บนเซิร์ฟเวอร์ GitHub
